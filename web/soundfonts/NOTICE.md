# Soundfonts

The port ships two unmodified versions of one soundfont:

- **Title:** Symbiote Soundfont
- **Creator:** NHP. The files' metadata names their engineer as Brian Salter.
- **Source:** <https://musical-artifacts.com/artifacts/7181>
- **License on that page:** [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/), with the extra note "(C) 2009 Beatnik Inc."

| File | Use in the port | SHA-256 |
| --- | --- | --- |
| `DroidSymbioteBank-BV.sf2` | The default | `76c83450d2046ee35c29f678cb6287ee73cbaf0e96fed152a99834fd2910ec2c` |
| `DroidSymbioteBank-BSD.sf2` | A choice in the soundfont menu | `8e34e2959714992a0e452757dd48e0fea419eeb8a15bbc6bf227659961deefc7` |

## What's in them, according to their creator

These statements come from the creator's description and the files' metadata, and haven't been checked independently.

The BSD version:

- Has only samples from the MiniBAE source repository, under the license below. Its copyright field reads "2003 Beatnik Inc. (BSD license)".

The BV (Bona Vacantia) version:

- Has samples from the MiniBAE source repository, under the license below.
- Has samples from mobileBAE, which the creator says was never cleared for release. The creator treats them as bona vacantia, and the file's copyright field reads "Bona Vacantia - Beatnik shut down 2011".
- Has the creator's own samples, licensed CC0: Bell, Church Organ, Brass Section, Square Wave, Synth Lead and Fifths.

The creator says the BV version contains no proprietary samples belonging to HMD Global Oy.
